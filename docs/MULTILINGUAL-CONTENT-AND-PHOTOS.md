# 다국어 게시글과 선수 사진 운영

## 게시글 작성

1. 뉴스 → 새 글 또는 편집을 열고 日本語·한국어·English 탭에서 제목·요약·본문·사진 설명을 작성합니다.
2. 일본어는 기존 기본 언어입니다. 쓰지 않는 한국어·영어는 비워 두며, 작성 중이라면 초안 저장이 가능합니다.
3. URL·카테고리·대표 사진·갤러리·게시일·예약은 세 언어가 함께 사용합니다. 미리보기에서 언어별 내용을 확인합니다.
4. 게시 또는 예약 버튼은 사용한 언어의 필수 항목을 확인합니다. 수정 이력을 복구하면 세 언어가 같은 버전의 비공개 초안으로 복구됩니다.
5. 공개 홈페이지는 기존 정기 재구축 후 해당 언어 내용을 표시합니다. 관리자 상단의 반영 상태를 확인합니다. 자동 번역 기능은 아닙니다.

구단·참여 소개에도 같은 언어 탭이 제공됩니다. 기타 앨범·미디어 설명·일정 등은 기존 번역 사전을 사용합니다. 기존 기사 번역은 그대로 제공되며 CMS 번역을 작성하면 그 내용을 우선합니다.

## 사진 분류와 선수 연결

1. 사진·영상에서 파일을 등록하고 사진 카테고리를 선수 사진·경기 사진·훈련 사진·기타 중 선택합니다. 카테고리 검색으로 분류별 목록을 확인합니다.
2. 미디어 화면에서 선수 사진을 먼저 등록할 수도 있습니다. Coach에게는 공개 승인된 사진만 선택 후보로 표시합니다. Owner·Administrator는 선수 양식에서 초안 사진도 선택하고 동의 확인 후 함께 승인할 수 있습니다.
3. 선수 관리의 새 등록·편집 창에서 선수 정보, 공개 프로필, 사진을 함께 작성합니다. Owner·Administrator는 이 창에서 사진을 직접 업로드하거나 기존 사진을 선택합니다. 새 업로드는 선수 사진 카테고리로 자동 분류합니다. Coach는 승인된 선수 사진을 선택합니다.
4. 같은 등록 양식의 공개 프로필에 이름·포지션·등번호·소개를 입력하고 저장합니다. 사진을 새로 선택하면 등록 사진과 공개 프로필 사진에 함께 적용합니다. 기존 사진을 변경하지 않으면 각각의 연결을 보존합니다. 선수 UUID는 고정됩니다.
5. 공개 프로필은 선수의 프로필·사진 동의 확인과 Owner/Administrator 승인이 있어야 게시됩니다. 선수 등록과 사진 선택만으로 공개하지 않습니다.

선수 사진을 바꾸려면 같은 선수 등록·편집 창에서 사진을 다시 선택하고 저장·승인합니다. 선수 사진이 연결된 미디어는 바로 삭제할 수 없으므로 먼저 선수 등록의 사진 연결을 해제합니다. 사진 동의를 철회하거나 사진을 비공개로 바꾸면 기존 안전 규칙에 따라 관련 공개 프로필도 비공개로 전환됩니다. 기존 네 활동 사진은 훈련 사진으로 분류되며 파일·동의·게시 상태는 유지됩니다.

## 편집 위치와 보호 규칙

- `src/lib/content-translations.ts`: 번역 필드, JSON 계약, 필수 항목 검사.
- `src/scripts/admin-translations.ts`: 입력 탭, 키보드 탐색, 작성 상태.
- `src/lib/admin-config.ts`: 사진 분류와 선수 등록의 사진 필드.
- `src/scripts/admin.ts`, `admin-list.ts`: 승인 사진 후보, 자동 제안, 사진 분류 검색과 저장.
- `src/data/locales/content.ts`: 승인된 CMS 번역 우선 적용. 슬러그·사진·수치는 공통 유지.
- 추가 SQL 마이그레이션: 번역과 분류 저장, 서버 검증, 복구 기본값. 기존 공개 RLS를 그대로 사용합니다.

선수의 `photo_asset_id`는 내부 선수 행의 참조입니다. 익명 API에서 선수 등록 데이터에 접근할 수 없으며, 공개 홈페이지는 승인된 공개 프로필의 `photo_path`만 읽습니다. DB 공개 권한을 넓히거나 버킷을 공개로 변경하지 않습니다. 새 선수·글·경기를 운영 DB에 임의 생성하지 않습니다.
