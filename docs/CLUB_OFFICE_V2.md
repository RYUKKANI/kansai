# CLUB OFFICE V2 변경 및 검증

관리자 공식 명칭은 **KANSAI UNITED FC — CLUB OFFICE**입니다. 운영 사이트 반영은 PR 검토 후 별도로 진행합니다.

## 화면별 변경

| 화면 | 변경 사항 |
| --- | --- |
| 공통 | 네이비 사이드바, 5개 메뉴 그룹, 아이콘, 현재 위치, 접기, 모바일 드로어, 계정·권한, 키보드 포커스 |
| 대시보드 | 실제 데이터 기반 통계와 필터 이동, 빠른 작업, 다가오는 일정, 승인·동의 확인, 일본어 작업 이력 |
| 뉴스 | 검색, 카테고리·상태 필터, 사진, 실제 작성 이력·수정일, 내용/사진/발행 구분, 안전한 미리보기 |
| 선수 | 내부 등록과 공개 프로필 구분, UUID 유지, 사진·포지션·등번호·공개 상태, 동의 미확인 시 발행 차단 |
| 경기·훈련 | JST 월간 달력 및 목록, 날짜 미정 안내, 날짜·장소·상태별 입력 그룹 |
| 미디어·구단·운영 멤버 | 기존 업로드·편집·초대 기능에 공통 표·폼·상태 UI 적용 |
| 편집·안내 | 미저장 경고, 로딩·빈 상태·오류·저장 알림, 저장과 공개 사이트 배포 상태 구분 |

## 주요 파일

- `src/layouts/AdminLayout.astro`, `src/pages/admin/index.astro`: 공통 화면 구조
- `src/styles/admin.css`: 요청한 색상 및 반응형 스타일
- `src/lib/admin-ui.ts`: 공통 UI, 메뉴, 상태, 필드 그룹
- `src/scripts/admin-dashboard.ts`: 실제 기록에 기반한 대시보드
- `src/scripts/admin-list.ts`: 검색·필터·페이지 이동·월간 달력
- `src/scripts/admin.ts`: 기존 인증/저장/업로드 유지, 화면 연결 및 편집 상태
- `tests/helpers/admin-app.mjs`, `tests/office.test.mjs`: 격리된 UI 검증
- `scripts/export-preview.mjs`: 내장 스크립트의 특수문자 치환 오류 수정

운영 DB, RLS, 회원가입 설정을 변경하지 않습니다. 기사 작성일과 작업자는 실제 이력에서 확인되는 경우에만 표시합니다. 조회할 수 없는 값은 추측하지 않습니다. 한 번에 전체 비공개 자료를 내려받지 않고 필요한 목록·사진·대상 이름만 조회합니다.

## 검증 결과

TypeScript/Astro 검사 0 오류·0 경고, 정적 사이트 11페이지 빌드, 오프라인 미리보기 11페이지 내보내기 완료. Node 테스트 23개와 실제 PostgreSQL 엔진의 권한·동의·게시 제약 검사 28개 통과.

테스트는 메모리 DB와 SDK 요청 대역을 사용합니다. 운영 DB에 가상 선수나 일정을 생성하지 않았습니다. 기존 로그인 수정은 별도 PR #4에서 배포되었고 사용자가 대시보드 진입을 확인했습니다. 이 PR의 새 화면은 실계정으로 아직 검증하지 않았습니다.

브라우저의 로컬 파일 접근 제한으로 새 화면의 픽셀 단위 시각 검토는 수행하지 못했습니다. 병합 전 HTTP 미리보기에서 PC·태블릿·모바일의 실제 배치와 일본어 글꼴을 확인해야 합니다. 일본어는 Noto Sans JP가 설치되어 있으면 사용하고, 없으면 시스템 일본어 글꼴로 표시합니다.

## 이후 범위

통합 월·주·목록 일정, 반복 훈련, 행사, 공개 일정, 자동 저장·예약 발행·내용 복구는 V3의 별도 기능 PR에서 확장합니다. 검색·알림 등 구현되지 않은 헤더 버튼은 추가하지 않았습니다.
